# Lottie-набір — Casino Game

Усі файли мають розмір 1920×1080 і прозорий фон, частота 30 fps. Персонажі вже стоять на своїх позиціях у сцені, тому шари просто кладуться один на одного на весь екран без зсувів. Картинки вбудовані у файли (WebP base64), зовнішніх ассетів немає.
Відтворювати через **lottie-web 5.12.x, renderer `svg`**. Спалах удару зроблено ефектом Fill, а `canvas` його не малює.

`preview.html` — сторінка, у якій уже все вбудовано. Відкривається подвійним кліком, потрібен інтернет, бо бібліотека lottie береться з cdnjs. На ній можна переглянути кожен файл окремо, а кнопка «Демо-раунд» програє сцену бою від початку до кінця.

## Шари (знизу вгору)
1. `bg_scene` — фон, цикл 12 с: рухаються хмари й туман, мерехтить смолоскип, летять іскри, світиться місяць.
2. `fx_focus_hero | fx_focus_enemy | fx_focus_clash` — фокус-світло, цикл 3 с. Перемикати кросфейдом контейнера 0.3–0.4 с через CSS opacity.
3. Персонажі: лицар і ворог чи бос.
4. `fx_boss_land_shake` — пил і хвиля від приземлення боса.
5. Попапи.

## Важливо для коду
- **Сума виграшу й кнопки в попапах не входять у Lottie.** Їх рендерить HTML поверх: сума і CTA New round / Menu з UI-kit. Плашка попапу займає (460,250) 1000×540 у координатах 1920.
- Тряску камери під час приземлення боса робить CSS-клас на контейнері сцени: `transform: translate` ±6px, 0.35 с, старт на 0.9 с. Приклад є в preview.html.
- Між файлами кожна поза — окремий кадр із Figma, тому перехід idle → attack відбувається стрибком. Щоб його згладити, варто робити кросфейд 60–80 мс між контейнерами або ставити наступну анімацію поверх і прибирати попередню через 2 кадри.
- Зіткнення: хто атакує — грає `*_attack`, а через ~0.27 с (у боса ~0.38 с) супротивник отримує `*_hit` або `*_dead`.
- Тіні під персонажами вже вбудовані в кожен файл.

## Джерела
`_source.zip` містить генератор на Python (`lot.py`, `rig.py`, `hier.py`, `build_*.py`) і нарізані з Figma частини (`parts/`, `bg/`, `pop/`). Тайминги та амплітуди правляться в `build_*.py`, після чого достатньо перезапустити генератор.
